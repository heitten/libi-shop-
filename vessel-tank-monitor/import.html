Upload the vessel's stability calculation workbook (the same "R14 Stab Calc … Dep./Arr. <port>.xlsx" file the Chief Officer produces) and this reads its Sounding Report sheet — the Fresh Water and Drill Water/Ballast tank readings it lists — and loads them straight into the Dashboard, no retyping. Everything happens in your browser; the file is never uploaded anywhere.

Fuel Oil, Cement and Mud tanks aren't on that report, so keep logging those on Daily Sounding as usual.
